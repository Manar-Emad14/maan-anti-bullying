# مَأمن | مساحتك الآمنة 🤝 (Ma'man | Safe Space)

تطبيق ويب تقدمي (PWA) متكامل مصمم لتوفير مساحة آمنة للاستماع، والدعم النفسي، والإبلاغ السري، والتوعية ضد التنمر المدرسي والإلكتروني.

---

## 🌟 الميزات المضافة والجاهزة

1. **💬 رفيق الاستماع «سند» (Interactive Listener):**
   - مساحة سرية وفورية للتفريغ والدعم النفسي.
   - يتفاعل بذكاء مع نوع الموقف (لفظي، جسدي، إلكتروني، حزن، شهود عيان) لتقديم التهدئة والخطوات العملية لحماية الطالب.
   - يحفظ المحادثة محلياً مع زر لمسح المحادثة بضغطة واحدة لحماية الخصوصية.

2. **🕊️ ركن «فضفضة آمنة» (Safe Wall):**
   - جدار تفاعلي لنشر المشاعر أو كتابة رسائل تشجيعية للزملاء بدون كشف الهوية.
   - زر التفاعل والدعم: **❤️ احتضان ودعم** مع احتساب عدد المتفاعلين.

3. **🔒 الإبلاغ الآمن ومتابعة الحالة (Secret Case Tracking):**
   - تقديم بلاغات سرية بمكان ونوع وتفاصيل الحادثة.
   - توليد كود سري للمتابعة (مثال: `TB-741920`).
   - إمكانية استعلام الطالب عن كوده لمعرفة رد وتوجيهات المرشد الطلابي.

4. **🔍 أداة «هل هذا تنمر؟» (Bullying Detector):**
   - استبيان سريع يحدد بدقة هل الموقف تنمر صريح يستوجب التدخل، أم خلاف عابر، أم مزاح غير لائق.

5. **💡 بنك النصائح والإشعارات الذكية:**
   - نصائح مصنفة حسب الفئة (للطالب، للزميل الشاهد، على الإنترنت، لأولياء الأمور والمعلمين).
   - زر للمشاركة المباشرة عبر **WhatsApp** أو نسخ النص.
   - لوحة تمكّن المشرف والمعلم من إضافة نصائح جديدة مباشرة إلى التطبيق.
   - نظام إشعارات بالمتصفح (Web Notifications API) وتنبيهات تفاعلية مستمرة.

6. **🫁 حقيبة التهدئة السريعة (SOS Grounding Toolkit):**
   - تمرين التنفس المهدئ **4-7-8** بدائرة بصرية متحركة.
   - تمرين الحواس الخمس **5-4-3-2-1** لتهدئة نوبات الهلع والتوتر.
   - أرقام وخطوط النجدة والمساعدة المباشرة مع إمكانية الاتصال الفوري.

7. **😊 مقياس المشاعر اليومي (Mood Tracker):**
   - يساعد الطالب على تحديد حالته النفسية اليومية وتلقي نصيحة ورسالة طبطبة مخصصة.

## 🚀 كيفية الرفع على Vercel

المشروع مُعد بالكامل ليعمل مباشرة على Vercel:

### الطريقة الأولى: عبر GitHub (الأسهل والأفضل)
1. ارفع ملفات هذا المجلد إلى مستودع على حسابك في **GitHub**.
2. ادخل على [Vercel.com](https://vercel.com) وسجّل دخولك.
3. اضغط على **"Add New Project"** ثم اختر المستودع الخاص بك.
4. اضغط **Deploy**، وسيتكفل Vercel بضبط كل شيء ونشره على رابط مباشر سريع وآمن بشهادة SSL (HTTPS).

### الطريقة الثانية: سحب وإفلات أو Vercel CLI
يمكنك تشغيل أمر:
```bash
npx vercel
```
أو سحب المجلد مباشرة في لوحة تحكم Vercel.

## 📱 التثبيت كتطبيق هاتف (PWA)
عند زيارة الموقع عبر هاتف (أندرويد أو آيفون):
- سيظهر شريط علوي: **«ثبّت التطبيق على هاتفك 📲»**.
- في متصفح Safari على iPhone: اختر زر المشاركة ثم **"Add to Home Screen"**.
- في متصفح Chrome على Android: اضغط **"تثبيت"** أو من القائمة **"Install App"**.
- سيعمل التطبيق بملء الشاشة وبدون اتصال بالإنترنت (Offline Mode).
